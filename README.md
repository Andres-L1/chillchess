## ✨ ¿Qué es ChillChess?

ChillChess es una plataforma de música ambiente diseñada para creadores de contenido, estudiantes y profesionales que buscan el entorno perfecto para trabajar, estudiar o crear sin distracciones.

### Características principales

- 🎵 **Catálogo curado**: Música lo-fi, chill hop, ambient y más géneros sin copyright
- 🎙️ **Ideal para streamers**: Compatible con OBS y otras plataformas de streaming
- 🌊 **Ambientes personalizables**: Mezcla música con sonidos de lluvia, café, naturaleza...
- 🎧 **Sin anuncios ni cortes**: Reproducción continua y fluida
- 🌙 **Diseño elegante**: Interfaz minimalista y moderna
